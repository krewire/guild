## Naming

File name: `{ProjectId}-{Scope}-{SpecID}-{slug}.md`. One spec per initiative.
`{ProjectId}` is the repo prefix (`KWG` here), `{Scope}` a short category,
`{SpecID}` a unique random 5-character alphanumeric code, `{slug}` a
kebab-case title. See the root `AGENTS.md` for the full convention.
